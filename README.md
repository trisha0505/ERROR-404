# E-Learning & Quiz Platform

## Overview

An interactive web-based learning platform designed to provide educational resources, quizzes, study materials, references, and user authentication features. The platform aims to enhance learning through engaging content and self-assessment tools.

## Features

- User Registration and Login
- Interactive Quiz System
- Study Material Access
- Learning References and Resources
- Chat Interface
- Performance Summary Dashboard
- Responsive User Interface
- Easy Navigation Between Learning Modules

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Frontend Web Development
